# ES - Info

## Objectif
Regrouper les TPs et exercices du module ES/Info.

## Dossiers
- `info/arebours`
- `info/Tp0-horodatage`
- `info/Tp1`
- `info/Tp2`
- `info/Tp3`
- `info/Tp4`
- `info/Tp5`
- `info/Tp6`
- `info/Tp7`

## Organisation
Chaque TP contient ses sources et, quand disponible, un `README.md` avec les
consignes, le build et l'execution.

## Build (par TP)
```sh
cd TpX
make
```

## Execution (par TP)
```sh
./<binaire>
```

## Installation (si supportee)
```sh
make install prefix=/chemin/vers/rootfs
```
